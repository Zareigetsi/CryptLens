# CryptLens
A cryptography and cipher analysis project.

## Goals

- Learn cryptography (fundamentals)
- Analyze classical ciphers
- Build cipher-breaking tools
- Document research findings (learnings)

## Project Structure

```text
docs/              Documentation

src/               Source code
tests/             Tests
data/              Sample datasets
assets/            Images and diagrams
```
